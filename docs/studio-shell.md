# فضای کار و ویرایش BEHIX

## مسیرها و ذخیره‌سازی

- `/projects` داستان‌های ذخیره‌شده را با نام و زمان تغییر نشان می‌دهد: ساخت، جست‌وجو، مرتب‌سازی، کپی، تغییر نام و حذف با تأیید. بازکردن از این صفحه با `/story?project=<id>` همان پروژه را انتخاب می‌کند.
- پروژهٔ جاری عکس‌سر، در صورت وجود در IndexedDB، جدا نمایش داده می‌شود. این مسیر هنوز یک پروژهٔ جاری دارد؛ چندپروژه‌ای شدن عکس‌سر و ذخیرهٔ دائمی صدا پیاده نشده است. پروژه‌های قدیمی localStorage از مسیر اصلی عکس‌سر بازیابی می‌شوند.
- بانک‌های `behix-story-projects` و `behix` ادغام نشده‌اند. تغییر مدل افزایشی است: فیلدهای جدید اختیاری‌اند و نبودشان رفتار قدیمی را حفظ می‌کند. هیچ رکوردی برای افزودن کنترل‌ها پاک نمی‌شود. مهاجرت نخستین داستان، اگر داشبورد قبلاً پروژه ساخته و متن قدیمی خالی باشد، پروژهٔ خالی اضافه نمی‌سازد.
- هنگام تعویض داستان و خروج از ویرایشگر، صف ذخیره تکمیل می‌شود. شکست ذخیره مانع کنارگذاشتن متن باز می‌شود؛ JSON هنوز قابل دریافت است. ذخیره محلی است، نه همگام‌سازی ابری. تعارض هم‌زمان دو تب هنوز حل نمی‌شود.

## ویرایش واقعی داستان

پنل «ویرایش بخش» مدت دیالوگ، روایت و مکث/عمل را تغییر می‌دهد؛ زمان‌بندی بعدی، زیرنویس و دهان دوباره کامپایل می‌شوند. حرکت کامل می‌شود؛ اگر زمان راه رفتن بیشتر باشد مدت بخش افزایش می‌یابد.

برای هر شخصیت، چهره، جای افقی، حرکت بدن، جابجایی، شیء دست و نشستن قابل تنظیم است. خوردن/نوشتن حالت نشسته دارند؛ مکان بدون صندلی هشدار می‌دهد. «بازنشانی بازی این شخصیت» ویرایش‌های آن شخصیت در همان بخش را پاک می‌کند. مکان و شب/روز برای کل صحنه‌اند. ویرایش جدید مکان از هر بخش همان صحنه جای قبلی را می‌گیرد؛ صحنه‌های هم‌نام مستقل می‌مانند.

همهٔ این کنترل‌ها به `StoryEdit` متصل‌اند: در تاریخچه، JSON و IndexedDB می‌مانند و preview/export از یک کامپایل استفاده می‌کنند. این رابط، ویرایش بخش‌های تولیدشده است؛ keyframe مستقل، جابجایی/تکثیر بخش و ویرایش transition هنوز ندارد.

مدت خودکار گفتار دیگر سقف ۹ثانیه ندارد: `0.45 + words/2.4` با حداقل۱٫۴ثانیه، به‌علاوه۰٫۱۸ثانیه برای مکث کوتاه و۰٫۳ برای نشانهٔ پایان جمله. این تخمین قابل ویرایش است و تلفظ واقعی را تشخیص نمی‌دهد.

## ویرایش عکس‌سر و موتور

در `/stage` جای افقی دو شخصیت اصلی (۱۲ تا۸۸٪) و اندازه (۷۰ تا۱۲۰٪) به document وصل است؛ دوربین نزدیک هم جای تازه را دنبال می‌کند. قاب و عدسی انتخاب‌شده همچنان ممکن است بخشی از بدن را خارج قاب قرار دهد. فیلدهای نامعتبر هنگام ورود پروژه ترمیم می‌شوند.

حل IK برای هدف منطبق با مبدأ طول استخوان‌ها را حفظ می‌کند. اشک از تابع زمان/شناسه ساخته می‌شود؛ به تاریخچهٔ فریم یا تصادف وابسته نیست. پخش فیلم و خروجی از زمان نسبی فیلم استفاده می‌کنند. دهان خارج مدت دیالوگ بسته است. تحلیل صدای موجود همچنان تقریبی است و همگام‌سازی واجی محسوب نمی‌شود.

خروجی عکس‌سر لغو دارد. خطای ضبط، قطع track، پنهان‌شدن صفحه و timeout پیام می‌دهند؛ finally منابع را آزاد می‌کند. preload تصویر خراب خطا می‌دهد تا خروجی موفق با تصویر جایگزین گزارش نشود. مسیر WebCodecs هنوز به رمزگذار واقعی مرورگر وابسته است؛ fallback با زمان واقعی و احتمال افت فریم عرضه می‌شود.

## موبایل

در عرض کمتر از۹۰۰px، متن، صحنه و ویرایش بخش پنل‌های قابل تعویض‌اند؛ بوم مشترک می‌ماند. خروجی در بخش بازشونده است. کنترل‌های موبایل حداقل۴۴px ارتفاع دارند. روی دسکتاپ پنل‌ها هم‌زمان قابل مشاهده‌اند. تصویرهای آزمون۳۹۰px و گزارش اندازه‌گیری در Outputs این task قرار دارند.

## آزمون‌ها

```sh
node scripts/run-tests.mjs
node scripts/story-studio-check.mjs
STUDIO_PHOTO_ONLY=1 node scripts/story-studio-check.mjs
STORY_VISUAL_ONLY=1 node scripts/story-browser.mjs
npm run typecheck
npm run lint
env -u DATABASE_URL npm run build
```

آزمون‌های مرورگر به Chromium مشترک Preview متصل می‌شوند. `story-studio-check` از context جدا، IndexedDB واقعی، Canvas واقعی، PNG دستی و WAV آزمایشی استفاده می‌کند؛ detector یا TTS را اجرا نمی‌کند. خروجی فیلم با decoder مرورگر و MediaBunny بررسی می‌شود. تصویر baseline جدید تنها پس از بررسی انسانی/دیداری جایگزین شود؛ `STORY_VISUAL_CANDIDATES=1` فقط نامزد می‌سازد و تأیید baseline نیست.

وابستگی جدیدی اضافه نشده است. فایل‌های سکو، auth و سیاست ثبت‌نام تغییر نکرده‌اند. محدودیت‌های باقی‌مانده: ذخیرهٔ صدای عکس‌سر، چندپروژه‌ای عکس‌سر، ویرایش کامل shotها، کشیدگی پس‌زمینه در landscape، ارزیابی دستگاه واقعی و بهینه‌سازی فیلم‌های طولانی.

## چیدمان تازهٔ ویرایشگر (الهام از Plotagon، Animaker، TupiTube و Animation Desk)

- `/` خانه و گالری پروژه‌هاست (کارت هر پروژه با تصویر واقعی از فیلم). `/projects` همان صفحه است. مسیر عکس‌سر به `/photo` رفت.
- ویرایشگر `/story`: نوار بالا (پروژه‌ها، نام، برگرداندن/از نو، خروجی) · ستون متن/بازیگران/صحنه‌ها/راهنما · صحنهٔ نمایش با کنترل پخش · پنل «ویرایش بخش» · خط زمان کلی پایین. در عرض کمتر از ۱۰۲۴px صحنه و خط زمان بالا ثابت‌اند و پنل‌ها با نوار پایین عوض می‌شوند.
- موتور: نمای دوربین دستی برای هر بخش (`shot`: باز/متوسط/نزدیک)، برگهٔ استوری‌بورد PNG (`storyboard.ts`)، خروجی فریم فعلی، پیش‌نمایش مکان‌ها و شخصیت‌ها (`previews.ts`).
- داستان‌های آماده از برنامه حذف شدند؛ متن‌های نمونه فقط برای آزمون تصویری در `tests/story/fixtures.ts` مانده‌اند.
- میان‌برها: فاصله پخش/توقف، ← و → بخش بعد/قبل، Ctrl+Z و Ctrl+Shift+Z.
